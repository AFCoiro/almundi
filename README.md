# <h1 align="center">almundi 🌎(work in progress)</h1> 
<br>


**Este sitio web fue desarrollado como parte de una entrega para Codo a Codo 4.0**, donde se requería implementar un proyecto utilizando únicamente **HTML, CSS y JavaScript**, sin frameworks ni preprocesadores. Tras completar la entrega y continuar el desarrollo en otro grupo, decidí mejorar este repositorio para que no quedara como un proyecto parcial e incompleto.  

## 📌 Descripción del proyecto  

El sitio actualmente utiliza un **JSON como base de datos** para la gestión de la información, aunque en el futuro se planea reemplazarlo por una **base de datos SQL** conectada con **Node.js**. Primero, quiero completar otros proyectos antes de avanzar con la parte de backend.  

Si bien la entrega no exigía un enfoque con cliente, **una persona asumió el rol de "cliente ficticio"** y me solicitó requerimientos concretos en cuanto a la estética funcionalidad del sitio y plazos. Esto permitió trabajar con un enfoque más realista, ajustando el diseño y la experiencia de usuario según sus exigencias.  

## ⚙️ Tecnologías utilizadas hasta el momento  

- **HTML** → Estructura del sitio  
- **CSS** → Estilos y diseño responsivo  
- **JavaScript** → Interactividad y manejo de datos desde un JSON  

🚫 **No se permitió el uso de frameworks ni preprocesadores como SASS** en esta entrega.  

## 🔜 Próximos pasos  

Actualmente, este repositorio contiene únicamente la parte **front-end** del proyecto. El desarrollo del **backend** se realizó en otro repositorio dentro de un grupo diferente como parte de la entrega para la certificación en backend. En el futuro, se planea:  

- Reemplazar el JSON por una **base de datos SQL**. 
- **Agregar una base de datos para alojar nuevos usuarios**, permitiendo registros y autenticación.  
- Implementar la conexión con el backend utilizando **Node.js**.  

## 🚀 Estado del proyecto  

✅ **Front-end finalizado** (según los requisitos de la entrega).  
⏳ **Backend pendiente** (planeado para una fase futura).
